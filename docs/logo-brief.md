# ロゴの指示書: あるばい

ロゴを作る人（デザイナーや画像生成 AI）に渡すための文書です。

## 1. 一言でいうと

**あるばい**は、災害のときに「今、どこで水と食べ物がもらえるか」を地図に出すアプリです。
アプリを使う人の位置情報から、いつもと違う人の集まりを自動で見つけます。そのうえで近くの人に「ここに何がある？」と聞いて確かめ、地図に載せます。

- 名前は熊本弁で「あるよ」という意味です（2026-11-05 に決定）
- キャッチコピーは「人の動きが、いちばん速い災害情報になる」です

## 2. 背景（なぜ作るのか）

- 発案者は熊本県八代市の出身です。2016年の熊本地震と2025年8月の八代市の豪雨で、自身が被災しました。2026年7月の熊本地震では、実家と友人が被災しました
- 被災中に一番欲しかったのは「今、どこで水と食べ物がもらえるか」でした
- 本当に助かったのは、**お店が店の前でやっていた炊き出しや商品の配布**です。ただ、こうした自主的な活動は市役所やテレビといった公式の情報には出てきません。知る方法は SNS とお隣さんだけでした
- 情報を得るには、「知っていたら教えて」「拡散して」と人に頼む必要がありました。**つながりがない人には届きません**

あるばいは、誰かの投稿を待たずに、人の動きから「ここにある」を見つけます。

## 3. ロゴで伝えたいこと

ロゴが伝えたいことを、優先順に並べます。

1. **「あるよ」と教えてくれる安心感**: 不安なときに、お隣さんが教えてくれるような温かさを出す
2. **人が集まる場所**: 人の点が自然に集まって1か所になるイメージ（検知の仕組みそのもの）
3. **地図・場所**: 地図に載ること（ただし、よくある地図ピンだけで終わらせない）

雰囲気は、落ち着いていて信頼できて、少しだけやわらかいものにします。災害時に開くアプリなので、明るく騒がしい表現や怖がらせる表現は避けます。

## 5. 色

アプリの画面の色（`web/style.css`）に合わせます。

| 役割 | 色 | 画面での意味 |
|---|---|---|
| 主の色 | 紺 `#1e3a5f` | 確認済みの非公式拠点、主なボタン。スライドも紺が基調 |
| 差し色（使うなら1色だけ） | オレンジ `#ea8a00` | 確認待ちの候補 |
| 背景 | 白 `#ffffff` | |

- 緑 `#0f7b4f` は、画面で「公式の避難所」を表す色です。ロゴの主役には使いません（公式と混同されるため）
- 色の数は2色まで。紺1色だけでも成り立つ形にします


## 7. 避けること

- **災害を直接描くもの**: ひび割れ、炎、波、壊れた家など。使う人を怖がらせるため
- **公的機関に見えるもの**: 避難所の案内図記号に似せた形、日の丸、自治体の紋章など。このアプリは公式の情報ではないので、誤解を招く
- **実在の団体やキャラクター**: くまモン、熊本城、他社のロゴに似た形
- **地図ピンだけのもの**: 今の仮アイコン（紺の角丸四角に白い地図ピン、`web/icon.svg`）がこれです。ありふれているので、置き換えたい
- **報道写真や SNS の画像を元にすること**: 著作権があるため
