# セキュリティと個人情報の扱い

> 守りの実装は `app/main.py`・`app/rules.py`・`app/ratelimit.py`・`app/auth.py`・`app/detect_job.py`。数値を変えるときはそれぞれの定数と `compose.yaml` の環境変数。

## 1. 何を守るか

| 守りたいこと | 脅威 |
|---|---|
| 一人ひとりの位置と移動を外に出さない | 位置の漏えい、個人の特定 |
| 嘘の拠点を地図に載せさせない | 遠くからの回答、自作自演の確認、大量の報告 |
| サーバーと DB を止めさせない | 大量の書き込み、巨大な送信 |
| 対象の災害地域の外から荒らされない | 無関係な地域からの参加 |

## 2. 入れている守り

### 2.1 参加と位置

| 守り | 中身 | 場所 |
|---|---|---|
| アカウントなしの匿名セッション | 参加のたびに乱数のトークンを発行し、DB には SHA-256 のハッシュだけ置く（DB が漏れてもなりすませない）。名前・電話・端末 ID は受け取らない | `app/auth.py` |
| 送り方 | `Authorization: Bearer <token>`。Cookie にしないので CSRF 対策が要らず、ネイティブでも同じ | `app/auth.py` |
| 失効 | 最後の利用から 30 日で使えなくなり、検知の定期処理が消す（位置・回答・通報も ON DELETE CASCADE） | `SESSION_TTL`、`detect_job._cleanup` |
| 対象地域の中の人だけ | `AREA="lat,lon,半径m"`（既定 八代市役所から 25km）。参加（`POST /v1/sessions`）に今の位置が要り、外なら 403。外の位置の点は捨て、外からの報告は 403。空にすると制限なし（テスト・開発） | `rules.area()`・`rules.in_area()` |
| 位置の時刻の検査 | `recorded_at` が 5 分より未来、または保存期間（14 日）より古い点は捨てる | `post_locations` |
| 位置の保存期間 | 14 日で消す（「いつもの場所」の学習に使う 7 日より長く、それ以上は持たない） | `detect_job.RETENTION` |
| 自分で消せる | 「参加をやめる」= `DELETE /v1/sessions/me` で、位置・回答・通報・自分だけが知らせたピンが消える | `app/main.py`、`spots.forget_session` |

### 2.2 嘘の拠点を防ぐ

| 守り | 中身 | 場所 |
|---|---|---|
| 近くの人だけ答えられる | 回答（`POST /v1/candidates/{id}/answers`）に今の位置が要り、候補から 500m（`QUESTION_RADIUS_M`）より遠いと 403。遠くから「終わっていた」を押す・自分の報告を別の端末で確かめる、を防ぐ | `post_answer` |
| 1 人 1 候補 1 票 | 回答は上書き（`UNIQUE (candidate_id, session_id)`）。通報も 1 人 1 備考 1 回 | `db/init.sql` |
| 確認は別の人 | 報告の候補は報告者を含めて 2 人の回答で確認済み。自分の報告は自分では確認できない | `rules.CONFIRM_ANSWERS` |
| 終了は多数決 | 「もう終わっていた」が「やっている」以上で終了 | `spots._refresh_status` |
| 備考の検査 | 100 文字まで、URL・電話番号は不可（全角も正規化して検査）、通報 2 件で非表示 | `rules.clean_note`、`NOTE_HIDE_FLAGS` |
| 自動で消える | 最後の確認から 6 時間で地図から消える。放置された嘘が残り続けない | `rules.HIDE_AFTER` |

### 2.3 サーバーを守る

| 守り | 中身 | 場所 |
|---|---|---|
| 回数制限 | 参加の開始は IP ごとに 1 時間 20 回（IP は接続元。`TRUST_PROXY=1` のときだけ、前段が `X-Forwarded-For` の末尾に付け足した値を使う。先頭は端末が書き換えられるので使わない。compose は同じマシンの前段を通す前提なので 1）、位置の送信はセッションごとに 1 分 10 回、回答・報告・通報は 1 時間 60 回、地図の読み込みは 1 分 60 回。超えると 429。`RATE_LIMIT=off` で止める（テスト） | `app/ratelimit.py` |
| 大きさの上限 | 位置は 1 回 1000 点まで、備考 100 文字、地図の非公式の拠点は 1 回 500 件まで（`rules.MAX_SPOTS`）。コンテナのメモリは api・db とも 1 GB まで（`compose.yaml` の `mem_limit`、上限で止まったら自動で立ち上げ直す） | pydantic |
| 入力の検査 | 座標の範囲、種類の列挙、時刻は時差つき必須。SQL はすべてパラメータ（文字列連結しない） | pydantic、`app/spots.py` |
| 認証なしの口は 2 つだけ | `POST /v1/sessions` と `GET /healthz`。それ以外は閲覧もセッション必須 | `app/auth.py` |
| 静的ファイル | 画面は API と同じオリジンから配る。CORS は開けていない | `app/main.py` |

### 2.4 検知のプライバシー

- 検知は「その人のいつもと違う滞在」を数えるが、外に出るのは **マス（500m）× 時間帯 × 人数** だけ。個人の軌跡や自宅は `candidates` に入らない
- 自宅の周り 200m は数えない。5 人未満の集まりは候補にしない（少人数の集まりは表示しない）
- 学習結果（自宅・いつもの場所）はプロセスのメモリに 24 時間だけ持ち、DB には書かない

## 3. 守れていないこと（正直に）

| できないこと | なぜ | 代わりに |
|---|---|---|
| GPS の偽装 | 端末が送る位置を信じるしかない | 候補は現地の人の回答で確定する。偽の集まりを 1 人で作るには近くに複数の端末が要る。確定後も 6 時間で消える |
| 複数の端末・ブラウザでの多重参加 | アカウントがない | 回数制限と「近くの人だけ」で手間を増やす。実地実験で問題が出たら、電話番号なしの端末ごとの署名（App Attest / Play Integrity）を検討 |
| 回数制限はプロセス内 | ワーカーを 1 つで動かす前提 | ワーカーを増やすときは Redis 等に移す（`docs/architecture.md` §8） |
| 通信の暗号化 | localhost は HTTP | 公開は必ず HTTPS（TLS のある前段を置く）。スマホの位置取得も HTTPS が条件 |
| 前段のログ | 位置は URL に入れず本文で送る（`POST /v1/questions`）。uvicorn のアクセスログも止めている（`--no-access-log`）。地図の表示範囲（`GET /v1/spots?bbox=`）は URL に入るので、前段の記録には残る | 前段の記録の保存期間を決めて消す |

## 4. 運用で守ること

- **公開は HTTPS で**（TLS 付きのリバースプロキシなど、使う人の環境で用意する）。`AREA` を対象地域に合わせ、`RATE_LIMIT` は切らない
- **ワーカーは 1 つ**（`uvicorn` の `--workers` を増やさない）。検知の定期処理と回数制限がプロセス内で動いているため
- **DB の中身を公開しない**。`location_points` は 14 日で消えるが、それまでは位置の点列が残る。バックアップを取るなら同じ扱いで
- **秘密は Git に入れない**。DB のパスワードは `compose.yaml` の開発用（`app/app`）だけ。公開運用では環境変数で差し替える。記入フォームの回答（`survey-answers*.json`）もコミットしない（`data/.gitignore`）
- **発表のデモは位置を取らない**（`demo` ブランチ）。本番の画面と混ぜない
- 依存パッケージは `uv.lock` で固定。更新は `uv lock --upgrade` → テスト → コミット

## 5. 脆弱性を見つけたら

GitHub の Issue に書いてください（位置情報に関わるものは、再現手順を公開 Issue に書く前に、まず概要だけで構いません）。

## 6. 確かめ方

```sh
docker compose exec api pytest -q tests/test_api.py   # 地域外の参加 403・位置なし 422、外の点を捨てる、遠くからの回答 403、回数制限 429 など
curl -s -X POST localhost:18080/v1/sessions -H "Content-Type: application/json" -d '{"consent":true,"lat":35,"lon":139}'   # → 対象地域の外では参加できません
```
